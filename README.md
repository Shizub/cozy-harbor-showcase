# Cozy Harbor

**A cozy multiplayer island game for Roblox.**

Fish, dig, catch bugs and craft on an island of your own, then meet friends in a shared harbour.

</div>

> **In active development.** The source code is private. This page only shows how the project is progressing.

## The game

- **Your own island.** It is saved between sessions and waits for you on the next visit.
- **A shared archipelago.** A hub island plus personal islands, with up to six players per server.
- **Everyday cozy activities.** Fishing, bug catching, digging and crafting.
- **A living world.** A day and night cycle, plus a real-world calendar for seasons and events.
- **Made for phones.** Mobile-first controls and short, readable text.
